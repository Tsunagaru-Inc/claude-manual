## Claudeデスクトップアプリのナビゲート：Chat、Cowork、Code

Claudeデスクトップアプリは、Claudeと連携する3つの方法を提供します：Chat、Cowork、Code—クイックな質問から複雑なリサーチからソフトウェアの構築まで。

Chatはあなたがclaude.aiから知っているのと同じClaudeですが、クイックエントリ、スクリーンショット、ディクテーション、そしてコンピュータ上でネイティブに実行できるコネクタを備えています。Coworkはより多くのことをするための機能と余裕を提供します。この幅広いスコープは、より徹底的なリサーチと分析、そしてより複雑なドキュメントと成果物の製造を可能にします。Codeはソフトウェアを構築するためのもので、コードの記述とテストから展開まで、すべてを行います。

CoworkとCodeは同じエンジンで実行されます。どちらもClaudeコード—あなたのマシンの内部、独立した仕事ができる、サブエージェントを回転でき、長いタスクを維持できます。これにより、Claudeはリサーチと書き込みまたはソフトウェア構築のような大規模なタスクを独立して処理できます。

各モードはそれが機能する仕事の周りに設計され、重要なことを表示し、必要な場所で制御を与えます。

## Chat

![__wf_reserved_inherit](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/69a8c30634a6c3e545269791_69a8a456caa28723041a6eea_699e1b746d83c9fb55a56d31_698be3352261cf694fdae308_698bdd295c5f5d680c01e63c_Screenshot%25252525202026-02-09%2525252520at%25252525204.38.22%25252525E2%2525252580%25252525AFPM.png)

Chatは、質問をしたり、ブレインストーム、下書き、またはバックフォースで問題を解決する必要があるときに優れています。

Claude.aiを使用した場合、これは同じ方法で機能しますが、コンピュータ上でネイティブに実行することからもたらされるいくつかのことがあります：

- **クイックエントリ。** Mac上のOptionキーをダブルタップして、取り組んでいることの上にClaudeを表示します。コンパクトなウィンドウに応答し、アプリの間で切り替わるとき、トップに留まります。作業をしているものを離れて質問をする必要はありません。
- **スクリーンショットとウィンドウ共有。** スクリーンショットをキャプチャするか、ウィンドウを共有してClaudeが正確に何を見ているかを確認します。画面上の内容を説明するより速く、より正確です。（Mac）
- **ディクテーション。** タイプする代わりに問題を解決してください。大声で考えるとき、キーボードから離れているとき、または話すことが速いときに有用です。（Mac）
- **デスクトップコネクタ。** ローカルツールとサービスをコネクタ経由で接続し、Claudeはマシンの他のツールで機能することができます。

**これを試すとき：**

- 不慣れなダッシュボードを見ていますクイックエントリを使用して、ウィンドウ上でカーソルをドラッグしてスクリーンショットし、「これらのメトリクスは何を意味していますか？」と聞きます。Claudeはダッシュボードが見える状態でオーバーレイで応答します。
- あなたは会議の間にあり、プレゼンテーションを構造化する方法について考えたいです。クイックエントリを開き、音声に切り替え、それを考えてください。Claudeはあなたが言ったことからアウトラインを下書きします。
- あなたはApple Notesで数週間製品ローンチについてのアイデアを記録しており、Notes コネクタを設定で追加し、Claudeに「Osprey ローンチについて私のメモのすべてを集計し、半分終わった場所を把握し、他の接続ツールで何か不足しているかチェックしてください」と聞きます。Claudeはマシン上のメモを読み、持っているものをピースにしてから、あなたが終わった場所をフォローアップします。

## Cowork

![__wf_reserved_inherit](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/69a8c30634a6c3e54526979c_69a8a456caa28723041a6ee7_699e2c4828218e71872531df_699e289b7bffb76b5ebedc79_Screenshot%252525202026-02-24%25252520at%252525202.39.06%252525E2%25252580%252525AFPM.png)

Claude Coworkは、実際の努力がかかる仕事のために構築されています：多くのソースから情報を引く、それを理解する、終わったものを生産する。

Claudeはマルチタスクでき、プロジェクトのさまざまな部分に一度に取り組むことができるため、より多くのソースから描画するためのスコープと物事を通じて見るためのスタミナがあります。徹底的なリサーチブリーフ、クロスソース財務分析、エンドツーエンドの契約審査、ソース全体に広がるマテリアルから磨かれたスライドデック。

開始する前に、Claudeは、必要なものを確認するために短いセットの質問をしばしば尋ねます：スコープ、形式、制約。サイドバーで確認できる計画を構築します。それが機能するとき、タスクが一緒に来るのが見えます：それが描いているソース、形成されているファイル、計画を通じた進歩。同時に複数のタスクを実行でき、それぞれはそれ独自の会話にあり、サイドバーからそれらの間で切り替わります。

- **フォルダアクセス。** Claudeにコンピュータ上のフォルダを与えて、そこに何があるかを読みます。関連するものを把握し、終わった仕事を同じ場所に保存します。ファイルをアップロードしたり、会話に内容を貼り付けたり、Claudeが必要なものを引き込むツールを接続することもできます。
- **スケジュールされたタスク。** Claudeは定期的なスケジュールで定期的な作業を処理できます：SlackとカレンダーからプルするDaily Briefing、出荷されたものの週間ラウンドアップ、あなたの注意が必要なソートを必要とする朝のインボックストリアージ。タスクと実行時期を定義し、Claudeは自動的にアプリが開いている度に処理します。コンピュータまたはアプリが期限のときに閉じられた場合、あなたが戻ってくるときにキャッチアップします。
- **ブラウザ使用。** ChromeでClaudeを接続し、Claudeはウェブサイトをナビゲートでき、ページと相互作用し、見つけたものを取り組んでいるタスクに直接引き込むことができます。これは、10のサイト全体で競争相手の価格をチェックしたり、APIがないページからデータを収集したりするようなCoworkの方法です。
- **プラグイン。** プラグインはClaudeに独自の機能を与えます：ライブの財務データをプル、会社の内部知識ベースを検索、または特定のコンプライアンスフレームワーク内で機能します。タスクに合わせてCoworkインターフェイスから閲覧して追加します。
- **保護された環境。** Coworkはコンピュータの格納された空間で実行されます。Claudeは共有したフォルダ内のファイルを読み取り、作成、編集できますが、外側のものにアクセスできません。

**これを試すとき：**

- すべてのツールをクエリするのと同様にデータベースを実行したい場合です。「前四半期について何を決めましたか？」と聞いて、Coworkはミーティングメモ、スライドデック、メール、Slackスレッド全体で答えを見つけます。
- 新しい市場を調査し、競合他社をスコープし、ツールを評価しています。情報を抽出するのが難しい複数のタブをスパンするかもしれない。リサーチの場合、Coworkはサイトを訪問し、レポートを読み、価格をプルし、あなたが単一のブラウザタブを開くことなく、ソース付きの構造化されたブリーフを配信します。
- 詳細が重要な大型ドキュメントを解析する必要があります：契約、財務報告書、会議のトランスクリプト。Coworkはすべてのページを読み、完全なセット全体でクロスリファレンスし、すべてのパターンを読むことから出現するパターンを引き出します。50のような5を確認します。
- あなたは毎朝同じ仕事を保ち続けます—メッセージをチェック、ステータスアップデートを一緒に引き、議題の会議のための準備。それを一度としてスケジュールされたタスクとして設定し、Claudeはリピート時にそれを処理するので、あなたは管理ではなく答えで日を開始します。

Coworkは現在リサーチプレビュー機能であり、Pro、Max、Team、Enterprise ユーザーが利用でき、定期的に新しい機能が追加されています。

## Code

![__wf_reserved_inherit](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/69a8c30634a6c3e545269794_69a8a455caa28723041a6ee1_699e1b736d83c9fb55a56d2a_698be3342261cf694fdae301_698bdd78a6031117e6bb41d6_Screenshot%25252525202026-02-09%2525252520at%25252525252012.52.07%25252525E2%2525252580%25252525AFPM.png)

Codeはデスクトップアプリ内の完全な開発環境を配置し、Claude Code で電力を供給します。

Claudeは直接あなたのコードベースで機能します：そこに何があるかを読み、コードを書いて変更し、コマンドを実行します。ビジュアルdiffsはどのようなものが変わったかを示し、組み込みのターミナルはコマンドの実行を示し、gitはすべてのバージョンを追跡して常に戻すことができます。

Coworkが共有したフォルダに限定された格納されたワークスペースで実行されている場合、Codeは完全なアクセス権を持つプロジェクトで直接実行されます。

仕事が発生する場所を選択します：

- **ローカル：** コンピュータ上のフォルダを選択し、Claudeはそれらのファイルで直接機能します。コンピュータで実行されるため、Claudeはプロジェクトを読み取り、ローカルツールにアクセスし、ブラウザで表示できる開発サーバーを実行できます。
- **リモート：** GitHub リポジトリを接続し、Claudeはクラウド環境で機能します。アプリを閉じても、セッションは続きます。そのため、大きなリファクターを開始してから後で戻ることができます。より大規模なコードベース、またはローカルマシンから開発を保つ必要があるときに良好です。

3つのインタラクションモードにより、Claude が独立して行う程度を制御できます：

- **Ask：** Claude は各変更を提案し、あなたが承認するまで待ちます。視覚的なdiffを確認し、何かが変更される前に受け入れるか拒否します。
- **Code：** Claude はファイル変更を自動的に適用しますが、ターミナルコマンドを実行する前にチェックします。
- **Plan：** Claude は何かに接触する前に、その完全なアプローチの概要を示します。専用計画ビューアーを使用すると、進行中に戦略を確認して再検討できます。

複数のプロジェクト全体でセッションを実行し、サイドバーからステータス（Active または Archived）と環境（Local または Cloud）でフィルタリングできます。

Codeタブはプロ、Max、Team、 Enterprise ユーザーにロールアウトされています。

## 3つのモードの比較

|  | Chat | Cowork | Code |
| --- | --- | --- | --- |
| **最適化される対象** | より速い交換：アイデアの探索、反復的なドラフト作成、クイック回答、対話を通じた学習 | 複雑または持続的な仕事：リサーチ、分析、ファイル編成、完成した文書と成果物の製作 | ソフトウェアの構築：コードの作成、テスト、実行、展開 |
| **主な機能** | クイックエントリ、ディクテーション | フォルダアクセス、プラグイン、サブエージェント、スケジュールされたタスク | Ask/Code/Planモード、ビジュアルdiffs、git統合、ローカル環境 |
| **ツールと拡張** | コネクタ、Skills、Chrome のClaudeコネクタ | コネクタ（ローカルおよびリモート）、Skills、Chrome のClaudeコネクタ、プラグイン | コネクタ、Skills、Chrome のClaudeコネクタ、プラグイン、Hooks |
