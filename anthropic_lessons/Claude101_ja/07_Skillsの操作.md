## Skillsの操作

**予想時間:** 15分

### 学習目標

このレッスンの終了時に、以下のことができるようになります。

- Skillsとは何か、Claudeがどのように使用するかを説明できる
- ドキュメント作成用のAnthropicのビルトインSkillsを特定できる
- 設定でSkillsを有効化および管理できる

---

### Skillsとは何か

Skillsは、Claudeが特定のタスクのパフォーマンスを向上させるために動的にロードする指示、スクリプト、リソースのフォルダです。それらを専門知識パッケージと考えてください。Claudeに、特定のタスクを反復可能な方法で完了する方法を教えます。

Claudeを使用してExcelスプレッドシート、PowerPointプレゼンテーション、Wordドキュメント、またはPDFを作成したことがあれば、Skillsはすでに機能しているのを見たことがあります。これらのファイル作成機能は、バックグラウンドで実行されているSkillsによって提供されます。

### Skillsの種類

あなたが遭遇するSkillsには2つのカテゴリがあります。

- **Anthropic Skills** はAnthropicによって作成および維持されます。これらには、Excel、Word、PowerPoint、PDFファイル用の拡張ドキュメント作成機能が含まれます。Anthropic Skillsはすべての有料ユーザーが利用でき、Claudeは関連する場合に自動的に呼び出します。何か特別なことをする必要はありません。
- **カスタムSkills** はあなたまたはあなたの組織が専門化されたワークフローとドメイン固有のタスク用に作成するものです。例えば、プレゼンテーションにブランドガイドラインを適用するSkill、会議メモを特定の形式に構成するSkill、または組織のデータ分析ワークフローを実行するSkillを作成できます。

### Skillsを有効にする

Skillsは現在、Pro、Max、Team、およびEnterpriseプランのユーザー向けの機能プレビューとして利用可能です。Skillsを使用するには、Skillsが安全なサンドボックスコンピュータ環境を必要とするため、コード実行とファイル作成を有効にする必要があります。

Skillsを有効にする方法は次の通りです。

1. **設定 > 機能**に移動します
2. **コード実行とファイル作成**がオンになっていることを確認します
3. **Skillsセクション**までスクロールします
4. 必要に応じて個別のSkillsをオンまたはオフにします

**Enterpriseプラン**の場合、組織の所有者は、個別のメンバーがアクセスできる前に、管理設定でコード実行とSkillsの両方を最初に有効にする必要があります。

**Teamプラン**の場合、この機能プレビューはデフォルトで組織レベルで有効になっています。

有効にすると、Anthropicのビルトインスキルとアップロードしたカスタムスキルを含む、利用可能なスキルが設定に表示されます。

### 実践でのSkillsの使用

Skillsの美しさは、通常それらについて考える必要がないことです。Claudeはリクエストに基づいてスキル選択を自動的に処理します。以下は、Skillsを呼び出すプロンプトの例です。

- 「月間支出を追跡する合計フォーミュラを含むExcelスプレッドシートを作成します」
- 「このミーティングノートドキュメントをPowerPointプレゼンテーションに変更します」
- 「このデータを要約するPDFレポートを生成します」
- 「シナリオ分析を含む財務モデルをExcelで構築します」

Claudeがスキルを使用すると、作業中の思考の鎖にそれが記載されます。出力はダウンロード可能なファイルになり、コンピュータに保存することも、Google Driveに直接保存することもできます。

### ファイル実行

この同じ機能は、Claudeがあなたの代わりに更新を行うために、**実際のファイル**(含まれた環境内)を操作できることを意味します。スライド、スプレッドシート、契約、(.xlsx、.pptx、.docx、.pdfファイル)をアップロードして、Claudeがスライドを作成し、分析を実行し、提案された編集を追加するのを観察します。Claudeが終了したら、これらのファイルをダウンロードするか、ドライブで開くことができます。

#### セキュリティに関する考慮事項

Skillsは実行可能なコードを含むことができるため、思慮深く使用することが重要です。

- 信頼できるソースからのカスタムSkillsのみをインストールしてください
- Anthropicのビルトインスキルはテストされ、Anthropicによって維持されています
- アップロードするカスタムスキルは、個人アカウントに非公開です

外部ソースからカスタムSkillsをインストールする場合は、使用する前に内容を確認して、それが何をするのかを理解してください。

### カスタムSkillsを作成する

Anthropicのビルトインスキルは一般的なドキュメント作成タスクをカバーしていますが、Skillsの実際の力はあなた自身を作成することから来ています。カスタムスキルは、特定のワークフロー、ブランドガイドライン、作業方法をClaudeに教えることができるため、Claudeはそれを自動的に関連するたびに適用できます。

カスタムSkillsを作成する最も簡単な方法は、Claude自体との会話を通じてです。コードを記述したり、手動でファイルを作成したりする必要はありません。Claudeが技術構造を処理します。

会話を通じてSkillsを作成する方法は次の通りです。

1. **新しいチャットを開始します** 。作成したいものについてClaudeに伝えます。例: 「四半期事業レビューを書くためのスキルを作成したいです」または「プレゼンテーションにブランドガイドラインを適用するスキルが必要です。」
2. **Claudeの質問に答えます。** Claudeはあなたのワークフローについてインタビューし、次のように尋ねます。このスキルは何をすべきですか? このタイプの作業の優れた出力は何ですか? このスキルをいつ使用する例を挙げてください。
3. **参照資料をアップロードします** (テンプレート、スタイルガイド、ブランド資産、仕事の例があれば)。これらはすべて、Claudeがあなたが探しているものを正確に理解するのに役立ちます。
4. **スキルをダウンロードします。** 完了すると、Claudeは適切に構成されたスキルを含むダウンロード可能なZIPファイルを生成します。
5. **設定にアップロードします。** **設定 > 機能**に移動し、Skillsセクションまでスクロールし、「Skillsをアップロード」をクリックして、ZIPファイルを選択します。

カスタムスキルは、Anthropicのビルトインスキルと並んでSkillsリストに表示されます。その時点から、関連するタスクに取り組むたびにClaudeは自動的にそれを呼び出します。手動でトリガーする必要はありません。

### SkillsとProjects

スキルとプロジェクトの両方を使用してClaudeにより多くのコンテキストを与える場合、いつ各を使用すべきかと思っているかもしれません。このように考えてください。**プロジェクトはナレッジを保存し、スキルはタスクを実行します。**

プロジェクトはナレッジハブです。Claudeが仕事を理解する必要があるリファレンス資料を保有しています。プロジェクト仕様、会議メモ、リサーチドキュメント。ファイルをプロジェクトにアップロードすると、Claudeはそのプロジェクト内のすべての会話全体でその情報を描画します。

スキルは手続き型機械です。それらは*どのように* Claudeがタスクを実行すべきかをエンコードします。毎回実行したい特定のステップ、操作の順序、方法論。スキルは反復可能なワークフロー全体を一貫して実行したいときに輝きます。

2つの機能は互いに補完されます。スキルはプロジェクトに保存されているナレッジを参照できます。たとえば、「顧客通話準備」スキルはプロジェクトのナレッジベースにアップロードされた顧客プロフィールから描画できます。プロジェクトは*何を*(情報)提供し、スキルは*どのように*(プロセス)提供します。

|  | プロジェクト | Skill |
| --- | --- | --- |
| **目的** | Claudeが参照するナレッジを保存 | Claudeが実行するプロセスを定義 |
| **最適な用途** | 長期コンテキスト、リファレンス資料、チームコラボレーション | 反復可能なワークフロー、複数ステップのタスク、一貫性のある方法論 |
| **例** | カスタマーハブ、リサーチバディ、フィードバックジェネレータ | ブランドガイドライン、ブログドラフト、PDF作成 |
| **永続性** | プロジェクト内のすべてのチャット全体で利用可能なナレッジ | スキルが呼び出されるときに適用される指示 |

### レッスン振り返り

先に進む前に、以下について検討してください。

- Claudeのビルトインスキルの恩恵を受ける可能性のあるドキュメントを定期的に作成しますか?
- あなたの仕事で反復可能なワークフローがあり、カスタムスキルの候補になりますか?
- スキルはドキュメント作成とデータ分析に関する考え方をどのように変えますか?
