## Claudeとは

**予定時間：** 15分

### 学習目標

このレッスンを終了すると、以下のことができます：

- Claudeが何かを説明し、その設計理念を理解する
- Claudeの基本機能と従来のチャットボットとの違いを説明する
- Claudeにアクセスするさまざまな方法（ウェブ、デスクトップ、モバイル）を理解する

### ビデオ：Claudeを思考パートナーに

（10分）

![](https://www.youtube.com/watch?v=VHsp6Hp7Stw)

このビデオではClaudeを単なるチャットボット以上のものとして紹介します。Claudeは思考パートナーとなるよう設計されたAIアシスタントです。Claudeが他のAIツールと異なる点と、それがさまざまな業務タスクでどのように役立つかを見ていきます。

#### 主な学習ポイント

- **Claudeは支援的で、害がなく、誠実であるよう構築されています**：高いレベルでは、Claudeは有害で差別的な出力を避け、違法または非倫理的な活動を支援しないよう導く原則に従っています。これは憲法的AI（Constitutional AI）と呼ばれるアプローチであり、Claudeが人間の価値観と一致し、透明性を持って動作するよう訓練されていることを意味します。
- **Claudeはチャットボット以上です**：Claudeは高い信頼性と予測可能性を保ちながら、さまざまな会話タスクとテキスト処理タスクを実行できます。要約、検索、創造的で協調的なライティング、質問応答、コーディング、その他多くのタスクに対応しています。Claudeは単に質問に答えるだけでなく、複雑な問題に取り組み、困難な状況を切り抜けるのを支援する思考パートナーと考えてください。
- **Claudeは操作可能で協調的に設計されています**：Claudeは性格、トーン、動作の方向付けを受け入れることができます。初期のお客様は、Claudeが有害な出力を生成する可能性が低く、会話しやすく、より操作可能であると報告しており、より少ないコストで目的の出力を得ることができます。
- **Claudeはどこからでもアクセスできます**：Claudeアプリはすべてのプラン種別（Free、Pro、Max、Team、Enterprise）で利用できます。サインイン時に会話、プロジェクト、メモリ、設定はすべてのデバイスで同期されます。机の上にいてもオンザロードでも、Claude.aiのウェブ、デスクトップ、モバイルアプリを通じてClaudeにアクセスできます。

### Claudeの機能を理解する

Claudeは単純な質問応答のインタラクションをはるかに超えた、広範なタスクを支援できます。アシスタント的なパートナーシップにより、仕事を自動化および強化できます。Claudeが優れている分野をいくつか紹介します：

- **ライティング・コンテンツ制作**：Claudeはソーシャルメディア投稿、ビジネスメール、複雑なレポートの作成で協力できます。Claudeは性格とトーンの方向付けを受け入れるよう訓練されているため、構造と明確性について一緒に反復処理し、あなたの声がはっきり伝わるまで調整できます。
- **リサーチ・分析**：Claudeはリサーチの角度を探索し、結果をまとめ、データを分析して有意義なインサイトを引き出すのを支援します。ドキュメントをアップロードすると、Claudeが複雑な情報の理解を支援します。これはClaudeの大規模なコンテキストウィンドウによって実現され、200,000トークン以上（約500ページ以上のテキスト）を処理でき、単一の会話で広範な資料を考慮できます。
- **コーディングサポート**：Claude Opus 4.5は当社の最も強力なモデルであり、世界最高のコーディングモデルです。実際のコーディングタスクでの強いパフォーマンスは、Claude が複数のプログラミング言語でコードの作成、デバッグ、説明を支援できることを意味します。
- **問題解決と推論**：Claudeは複雑な認知タスク、数学の問題、戦略的分析、リサーチを処理します。Claude Opus 4.5とSonnet 4.5はハイブリッドモデルであり、2つのモード提供します：ほぼ即座の応答と、より深い推論のための拡張思考。拡張思考により、Claudeは問題をステップバイステップで処理でき、慎重な分析が必要なタスクに適しています。
- **新しい知識を学ぶ**：新しいスキルを学んでいる場合、なじみのないドメインを探索している場合、複雑な課題に取り組んでいる場合のいずれでも、Claudeはあなたの学習スタイルとペースに適応できます。学習モードはClaudeの新しいエクスペリエンスであり、答えを提供するのではなく推論プロセスをガイドして、批判的思考スキルを育成するのに役立ちます。

Claudeの使用方法についてインスピレーションを得るには、claude.comの[ユースケースギャラリー](https://claude.com/resources/use-cases)を参照して、あなたの職務に関連する方法を探索してください。

### Claudeにアクセスする方法

Claudeはインテリジェンス—あなたがこのコース全体で協力するAIアシスタントです。同じインテリジェンスが複数のインターフェイスで利用でき、それぞれ異なるタイプのタスクに適しています。

- **[Claude.ai](https://claude.ai/)**（および関連するモバイルおよびデスクトップアプリ）は、ほとんどの人がClaudeと相互作用する主な方法です。ここで質問をしたり、アイデアをブレインストーミングしたり、ドキュメントを作成・編集したり、その他多くのことができます。Claude.aiは会話、ライティングサポート、リサーチ、分析、ファイル作成に最適です。これはこのコースの焦点です。
- **[Claude Code](https://claude.com/product/claude-code)**は開発者向けに設計されたエージェント型のコーディングツールですが、デスクトップ上のあらゆる種類のファイル操作に使用できます。Claude Codeはファイルの直接編集、コマンドの実行、コミットの作成ができます。
- **[Claude と Slack](https://claude.com/claude-and-slack)**は、チームのコミュニケーションツールに直接Claudeをもたらします。AIアシスタントヘッダーからチャネルまたは会話でClaudeとチャットするか、スレッドで@Claudeをメンションできます。SlackをClaudeに接続すると、Claudeはワークスペースのチャネル、ダイレクトメッセージ、共有ファイルを検索して、より良い応答とリサーチに必要なコンテキストを見つけます。
- **[Claude for Excel](https://claude.com/claude-for-excel)**により、Microsoft Excelのサイドバーで直接Claudeを使用できます。Claudeはexcelワークブックを読み取り、分析し、変更し、新規作成できます。Claude for Excelはモデル分析、前提条件の更新、エラーデバッグ、テンプレート作成、数式説明、マルチタブナビゲーションに最適です。

このコースは主に[Claude.ai](https://claude.ai/)に焦点を当てていますが、開発ワークフローでのClaudeの使用方法の詳細については、[Claude Code in Action](https://anthropic.skilljar.com/claude-code-in-action)も確認できます。
