## 深掘りのためのリサーチモード

**所要時間:** 15分

### 学習目標

このレッスンを終了した時点で、以下のことができるようになります:

- リサーチの機能（体系的で多角的な調査）について説明できる
- 包括的な情報収集にリサーチを使用する際を特定できる
- リサーチが拡張思考とどのように連携して詳細なレポートを提供するか理解できる
- 複雑な調査に対して効果的なリサーチプロンプトを作成できる

### ビデオ: Claude を使ったリサーチ

![](https://www.youtube.com/watch?v=R-KJgjIrh24)

#### 重要なポイント

- **リサーチは Claude が情報を見つけ、分析する方法を変えます。** 単一の検索ではなく、Claude は自律的に機能し、互いに基づいた複数の検索を実行しながら、次に何を調査するかを正確に判断します。自動的に質問の異なる角度を探索し、未解決の質問に体系的に取り組みます。
- **リサーチは数分で包括的な回答を提供します。** ほとんどのレポートは 5～15 分で完成しますが、より複雑な調査には最大 45 分かかることもあります。これは通常であれば何時間もかかるような作業です。
- **拡張思考はリサーチで自動的に有効になります。** この強力な組み合わせにより、Claude は自分のアプローチを思慮深く計画し、包括的な情報を収集し、複雑なリクエストを管理可能な部分に分割できます。
- **引用により検証が簡単になります。** リサーチは容易に確認できる引用付きの徹底的な回答を提供するため、Claude の検出に信頼でき、すぐに出典を自分で確認できます。

### リサーチモードとは

リサーチは、Claude を会話型アシスタントから体系的な調査者へと変える高度な機能です。リサーチを有効にすると、Claude は単に質問に回答するのではなく、複数の角度から質問を探索し、Web と接続済み統合から情報を合成します。

熟練したリサーチアシスタントが情報を集め、出典を相互参照し、包括的なレポートを作成するのに何時間もかけるのと同じですが、数分で完了します。

リサーチは、クイック回答以上のものが必要な場合に特に有用です。複数のソースから情報をまとめ、異なる視点を比較し、調査結果を実行可能な洞察に統合する必要がある状況に設計されています。

### リサーチを使用する際

リサーチと他の Claude の機能を使い分けることで、特定のニーズに最適な結果を得ることができます。

**リサーチが必要な場合:**

- 複数のソースから情報を統合した包括的なレポート
- Web と接続済み統合（Google Workspace など）にわたる詳細な分析
- 通常であれば何時間もの手作業を必要とする徹底的な調査
- 競合他社やベンダーオプションの評価など、比較分析
- 検証できる引用付きのレポート

**代わりに Web 検索を検討する場合:**

- 本日の株価や会社の住所など、クイックで具体的な事実が必要
- 回答が 1～2 のソースのみで十分
- 包括性より速度が重要

**代わりに拡張思考を検討する場合:**

- 外部情報が不要な複雑な問題の深い推論が必要
- 数学の問題、コードのデバッグ、論理的分析に取り組んでいる
- 情報収集ではなく、問題を推論することで回答が得られる

### リサーチの仕組み

リサーチを有効にすると、単純な Web 検索をはるかに超える複数段階のプロセスがアクティブになります。

1. **ステップ 1: Claude がアプローチを計画します。** リサーチが有効な場合、拡張思考は自動的にアクティブになります。これにより、Claude はリクエストを分解し、必要な情報を特定し、質問の異なる角度を調査する方法を計画できます。
2. **ステップ 2: Claude は複数の検索を実施します。** 単一の検索を実行する代わりに、Claude は互いに基づいた多くの検索を実施します。見つかったものに基づいて次に何を調査するかを判断し、有望なリードを追求し、ギャップを埋めます。
3. **ステップ 3: Claude が調査結果を統合します。** Web と Gmail、Google Calendar、Google Drive などの接続済み統合を含む複数のソースから情報を収集した後、Claude はすべてを包括的で整理されたレポートにまとめます。
4. **ステップ 4: Claude が引用を提供します。** リサーチレポート内のすべての主張はその出典に遡ることができ、情報の検証と必要に応じてさらに詳しく調べることが簡単になります。

### 実際のリサーチの使用

リサーチを有効にして使用する方法は以下の通りです:

1. チャットインターフェースの左下から**リサーチ**ボタンを探します
2. クリックして有効化します。リサーチがアクティブなときはボタンが青くなります
3. プロンプトを入力して送信します
4. Claude がバックグラウンドで機能し、検索と分析の進行状況インジケータが表示されます

**重要:** リサーチが機能するには Web 検索を有効にする必要があります。まだ Web 検索をオンにしていない場合は、検索とツール設定でオンにしてください。

#### 効果的なリサーチプロンプトのコツ

リサーチは複雑さに応じて 5～45 分かかることがあるため、プロンプトの作成に時間をかけることは有益です。いくつかの戦略を紹介します:

- **目標を具体的に説明します。** 「EV 市場について教えてください」ではなく、「電気自動車用バッテリー市場を分析してください。主要プレイヤー、技術トレンド、投資決定に影響する可能性のあるサプライチェーンの課題を特定してください」と入力してください。
- **セクションや構造を指定します。** Claude はその構造の周りに調査結果を整理します。たとえば、「会場オプションを比較してください。開始地点とアクセシビリティ、会議スペース・設備、ケータリング オプション、料金を含めてください」と言ってください。
- **関連する制約を含めます。** 予算範囲、タイムライン、地域要件、およびその他のパラメーターは、Claude が関連オプションに焦点を合わせるのに役立ちます。
- **Claude にプロンプトの改良を手伝ってもらいます。** リサーチ質問をどのように作成するか不確かな場合は、機能を有効にする前に Claude に より良いリサーチプロンプトを書く手伝いをさせることもできます。

#### 接続済み統合での作業

Google Workspace またはその他の統合が接続されている場合、リサーチはさらに強力になります。Claude は Web リサーチと一緒に、メール、カレンダー、およびドキュメントからコンテキストを取得できます。

たとえば、Claude に次のことを求めることができます:

- 「メールと Slack 全体で Project X について議論されていることをまとめて、その後、同様のイニシアティブのインダストリーベストプラクティスをリサーチしてください」
- 「来週のカレンダーのコミットメントを確認して、会う各企業をリサーチしてください」
- 「Google Drive のすべての内部ドキュメントで価格戦略について見つけて、競合他社がどのように自分たちを位置付けているかと比較してください」

統合によるリサーチを使用する場合、「Google Drive から関連するコンテキストを取得してください」または「このトピックに関する最近のメールから洞察を含めてください」と言うことで Claude を誘導できます。
