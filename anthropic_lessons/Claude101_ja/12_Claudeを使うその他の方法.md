## Claude を使うその他の方法

**所要時間:** 10分

### 学習目標

このレッスンを終了した時点で、以下のことができるようになります:

- Claude Code、Claude for Slack、Claude for Excel、Claude for Chrome など、追加の Claude 製品を使用する際を理解できる

---

このコースの最初に述べたように、Claude はインテリジェンスです。[Claude.ai](https://claude.ai/) はそれを使う1つの方法に過ぎません。

Claude はまた、既に作業している場所で出会うために設計された複数の専用ツールで利用可能です。このレッスンでは、Claude を使う4つの追加の方法を紹介します。それぞれ特定のワークフローとユースケースに合わせています。

### Claude Code

![](https://www.youtube.com/watch?v=s-avRazvmLg)

Claude Code は、ターミナル、IDE、ブラウザ、さらには Slack で作業する場所で機能するエージェント型のコードツールです。コードベースを理解し、コマンドを実行し、自然言語を通じて開発ワークフロー全体を処理します。

**Claude Code を使う際:**

- プレーンイングリッシュで必要なものを説明してコードを書き、テストを実行し、コミットを作成させたい
- エラーメッセージを貼り付けて、Claude がコードベースを分析して問題を特定・修正することが必要
- 慣れていないコードベースを操作していて、異なる部分がどのように連携しているか質問したい
- Lint エラーの修正、マージコンフリクトの解決、リリースノートの作成など、面倒な作業を自動化したい
- IDE を切り替えるのではなく、ターミナルで既存のツールと一緒に作業することが好み

### Claude in Slack

![](https://www.youtube.com/watch?v=tI1uzSJuSxc)

Claude は Slack と直接統合されており、チャネルとスレッドでサポートを得たり、Slack コンテキストを Claude での会話に持ち込むことができます。

**Claude in Slack を使う際:**

- Slack を離れることなく、メッセージへのレスポンスを起案したり、長いスレッドを要約したり、複雑な議論を分解したい
- 関連する会話と共有ドキュメントをワークスペースから整理して、会議の準備をしたい
- 新しいチームにオンボーディングされていて、チャネルの履歴を確認することでプロジェクトを理解するのに役立つ Claude を使いたい
- バグレポートまたは機能の議論から直接コーディングタスクを引き渡したい。@Claude とタグを付けると、周辺のコンテキストを使用して Claude Code セッションを開始できます
- 会話中に業界のトレンド、技術的な概念、または会社情報についての回答が必要

### Claude for Excel

![](https://www.youtube.com/watch?v=8ZRTSIRWLu4)

Claude for Excel は、サイドバーを通じて Microsoft Excel に Claude を直接提供し、会話を通じてスプレッドシートを分析、理解、変更することができます。

**Claude for Excel を使う際:**

- 複雑なマルチタブのワークブックを使用していて、特定の数式または計算フローがシート全体でどのように機能するかを理解したい
- 数式の依存関係と関係を保持しながら、モデル全体の仮定または入力を更新する必要がある
- #REF!、#VALUE!、または循環参照などのスプレッドシートエラーをデバッグして、Claude にそれらを出典までトレースして修正を提案させたい
- データを保有しながら新しいスプレッドシートを作成するか、既存のテンプレートに入力してから、適切な数式構造を保持したい
- ピボットテーブルまたはチャートをすばやく構築してデータを可視化したい

### Claude for Chrome

![](https://www.youtube.com/watch?v=IypXvHej9eY)

Claude for Chrome は、Google Chrome にサイドバーとして Claude を追加するブラウザ拡張機能です。作業中のものを観察し、ブラウザ内で直接アクションを実行できます。

**Claude for Chrome を使う際:**

- 閲覧中に記事、研究論文、Web ページを要約したい
- メールレスポンスを起案したり、受信箱を管理するのに役立つが必要
- 反復的なフォームを入力していて、プロセスを自動化したい
- Web サイト機能をテストしたり、複数のステップを含むワークフローを操作したい（各ステップを手動でクリックすることなく）
- タブとタスク間を移動する際にコンテキストを保持するブラウジングアシスタントが必要

**重要な注意:** Claude for Chrome は現在リサーチプレビュー中です。Anthropic は信頼されている Web サイトで低リスクのタスクに使用することを推奨します。拡張機能は購入またはパーソナルデータの共有など、高リスクのアクション前に許可を求め、特定のカテゴリの Web サイト（金融サービス、アダルトコンテンツ）はデフォルトでブロックされています。

**入手可能性:** Claude for Chrome は Claude Max サブスクライバーが利用できます。claude.ai/chrome でウェイトリストに参加してください。

---

### まとめ

これらのツールはそれぞれ、既に作業している特定の環境に Claude の機能を拡張します:

| ツール | 最適な用途 | 実行場所 |
| --- | --- | --- |
| Claude.ai | 一般的なタスク、リサーチ、作成、分析、ファイル作成 | Web、デスクトップ、モバイルアプリ |
| Claude Code | ソフトウェア開発、コードベース操作、git ワークフロー | ターミナル/コマンドライン、IDE、またはブラウザ |
| Slack での Claude/Claude Code | チーム協力、会議準備、コンテキストでのクイック回答 | Slack ワークスペース |
| Claude for Excel | スプレッドシート分析、財務モデリング、数式デバッグ | Microsoft Excel サイドバー |
| Claude for Chrome | Web リサーチ、メール管理、ブラウザ自動化 | Chrome ブラウザサイドバー |
